# 47. What is Redux Thunk ?

Redux Thunk is middleware that allows:

```txt id="x1m7qa"
Async Operations
inside Redux
```

Example:

* API Request
* Database Fetch
* Login Request
* Async await Logic

---

# 48. Why Redux Needs Thunk ?

Redux reducers MUST be:

```txt id="r8v2mc"
Pure Functions
```

Reducers CANNOT:

* Call API
* Use async await
* Use fetch directly

BAD Example:

```js id="m4v9pb"
reducers: {

    getPosts: async (state) => {

        const response =
            await fetch("/api/posts");
    }
}
```

This is WRONG.

# 54. Full Async Thunk Example

## redux/features/postSlice.js

```js id="y4m1pb"
import {

    createSlice,

    createAsyncThunk,

} from "@reduxjs/toolkit";


// ASYNC THUNK
export const getPosts =

    createAsyncThunk(

        "posts/getPosts",

        async () => {

            const response =

                await fetch(
                    "https://jsonplaceholder.typicode.com/posts"
                );

            const data =
                await response.json();

            return data;
        }
    );


// INITIAL STATE
const initialState = {

    posts: [],

    loading: false,

    error: null,
};


// SLICE
const postSlice =
    createSlice({

        name: "posts",

        initialState,

        reducers: {},

        extraReducers: (builder) => {

            builder

                // PENDING
                .addCase(

                    getPosts.pending,

                    (state) => {

                        state.loading =
                            true;

                        state.error =
                            null;
                    }
                )

                // FULFILLED
                .addCase(

                    getPosts.fulfilled,

                    (state, action) => {

                        state.loading =
                            false;

                        state.posts =
                            action.payload;
                    }
                )

                // REJECTED
                .addCase(

                    getPosts.rejected,

                    (state, action) => {

                        state.loading =
                            false;

                        state.error =
                            action.error.message;
                    }
                );
        },
    });

export default
    postSlice.reducer;
```

# 61. Full Component Example

## components/PostList.jsx

```jsx id="u9n6qw"
"use client";

import {

    useSelector,

    useDispatch,

} from "react-redux";

import { useEffect }
from "react";

import {
    getPosts
}
from "@/redux/features/postSlice";

export default function PostList() {

    const dispatch =
        useDispatch();

    const {

        posts,

        loading,

        error,

    } = useSelector(

        (state) => state.posts
    );

    // FETCH POSTS
    useEffect(() => {

        dispatch(getPosts());

    }, [dispatch]);

    // LOADING
    if (loading) {

        return <h1>Loading...</h1>;
    }

    // ERROR
    if (error) {

        return <h1>{error}</h1>;
    }

    return (

        <div>

            {

                posts.map((post) => (

                    <h1 key={post.id}>

                        {post.title}

                    </h1>
                ))
            }

        </div>
    );
}
```

# 65. Login Async Thunk Example

## authSlice.js

```js id="v6n1qw"
export const loginUser =

    createAsyncThunk(

        "auth/login",

        async (formData) => {

            const response =

                await fetch(
                    "/api/login",
                    {
                        method: "POST",

                        headers: {
                            "Content-Type":
                                "application/json",
                        },

                        body:
                            JSON.stringify(
                                formData
                            ),
                    }
                );

            return response.json();
        }
    );
```
