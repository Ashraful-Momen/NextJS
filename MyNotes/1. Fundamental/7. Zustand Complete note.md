# Next.js Complete Zustand Note

# 1. What is Zustand ?

Zustand is a lightweight global state management library for React and Next.js.

It helps manage:

* User State
* Cart State
* Theme State
* Auth State
* Global Data

WITHOUT prop drilling.

---

# 2. What is State ?

State means:

```txt id="z1m7qa"
Data that changes over time
```

Example:

* Counter Value
* User Info
* Login Status
* Cart Items

---

# 3. Local State vs Global State

| Type         | Scope             |
| ------------ | ----------------- |
| Local State  | Single Component  |
| Global State | Whole Application |

---

# 4. Local State Problem

```txt id="x4k9pb"
Component A
     │
     ▼
Component B
     │
     ▼
Component C
```

Passing data through many components becomes:

```txt id="r8v2mc"
Prop Drilling
```

---

# 5. Zustand Solves This

```txt id="t6n1qw"
Global Store
      │
      ├── Component A
      ├── Component B
      └── Component C
```

All components access same data directly.

# 11. Create First Store

## store/counterStore.js

```js id="n4v8ma"
import { create } from "zustand";

export const useCounterStore =
    create((set) => ({

        count: 0,

        increment: () =>

            set((state) => ({
                count: state.count + 1,
            })),

        decrement: () =>

            set((state) => ({
                count: state.count - 1,
            })),
    }));
```

# 16. Counter Component

## components/Counter.jsx

```jsx id="t1n6qb"
"use client";

import {
    useCounterStore
}
from "@/store/counterStore";

export default function Counter() {

    const {

        count,

        increment,

        decrement,

    } = useCounterStore();

    return (

        <div>

            <h1>{count}</h1>

            <button
                onClick={increment}
            >
                +
            </button>

            <button
                onClick={decrement}
            >
                -
            </button>

        </div>
    );
}
```

# 30. Persist Store Example

## store/authStore.js

```js id="t9v1rx"
import { create } from "zustand";

import { persist }
from "zustand/middleware";

export const useAuthStore =
    create(

        persist(

            (set) => ({

                token: null,

                setToken: (newToken) =>

                    set({
                        token: newToken,
                    }),

                logout: () =>

                    set({
                        token: null,
                    }),
            }),

            {
                name: "auth-storage",
            }
        )
    );
```

---

# 33. Zustand Selector

## BAD

```js id="w2t9mx"
const store =
    useCounterStore();
```

Gets ALL store data.

---

## GOOD

```js id="v4n7pb"
const count =
    useCounterStore(
        (state) => state.count
    );
```

Gets only required state.

---

# 34. Why Selector Important ?

Benefits:

* Better Performance
* Less Re-render
* Cleaner Component

# 35. Zustand Async Action

## Example API Fetch

```js id="s6m1qw"
import { create } from "zustand";

export const usePostStore =
    create((set) => ({

        posts: [],

        getPosts: async () => {

            const response =
                await fetch(
                    "/api/posts"
                );

            const data =
                await response.json();

            set({
                posts: data,
            });
        },
    }));
```
