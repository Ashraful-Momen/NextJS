# 1. What is SWR ?

SWR is a React hook library for:

```txt id="x1m7qa"
Client Side Data Fetching
+ Cache Management
```

Built by:

Vercel

---

# 2. What is ISR ?

ISR means:

```txt id="r8v2mc"
Incremental Static Regeneration
```

ISR is a Next.js feature for:

```txt id="u4k9pb"
Static Page Generation
+
Automatic Background Revalidation
```

---

# 3. SWR vs ISR Core Difference

| SWR               | ISR                 |
| ----------------- | ------------------- |
| Client Side       | Server Side         |
| CSR Fetching      | Static Regeneration |
| Runs in Browser   | Runs on Server      |
| Dynamic User Data | Static Public Data  |

# 12. Basic SWR Example

## components/PostList.jsx

```jsx id="n3m7qa"
"use client";

import useSWR from "swr";

import { fetcher }
from "@/lib/fetcher";

export default function PostList() {

    const {

        data,

        error,

        isLoading,

    } = useSWR(

        "/api/posts",

        fetcher
    );

    if (isLoading) {

        return <h1>Loading...</h1>;
    }

    if (error) {

        return <h1>Error...</h1>;
    }

    return (

        <div>

            {

                data.map((post) => (

                    <h1 key={post.id}>

                        {post.title}

                    </h1>
                ))
            }

        </div>
    );
}
```

# 43. Step 2 — SWR Client Component

## components/Comments.jsx

```jsx id="p8n6qw"
"use client";

import useSWR from "swr";

const fetcher =

    (url) =>

        fetch(url)

        .then((res) => res.json());

export default function Comments() {

    const {

        data,

        isLoading,

        error,

    } = useSWR(

        "https://jsonplaceholder.typicode.com/comments",

        fetcher
    );

    if (isLoading) {

        return <h1>Loading...</h1>;
    }

    if (error) {

        return <h1>Error...</h1>;
    }

    return (

        <div>

            <h1>

                LIVE COMMENTS

            </h1>

            {

                data.slice(0, 5).map((comment) => (

                    <p key={comment.id}>

                        {comment.name}

                    </p>
                ))
            }

        </div>
    );
}
```
