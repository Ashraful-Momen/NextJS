# Next.js Jobs + Queue System (Complete Simple Note)

---

# 1. What is a Queue System ?

A queue system is used to handle:

```txt id="q1"
Background tasks that should NOT run inside request
```

---

## Examples of Jobs:

* Send Email
* SMS notifications
* Image processing
* PDF generation
* Payment processing logs
* AI tasks
* Data sync with external APIs

---

# 2. Why Queue is needed ?

Without queue:

```txt id="q2"
User request → wait → slow response → bad UX
```

With queue:

```txt id="q3"
User request → instant response → job runs in background
```

---

# 3. Queue Architecture

```txt id="q4"
API Request
     │
     ▼

     │
     ▼

     │
```

# 8. Add Job to Queue (Producer)

## services/emailService.js

```js id="q9"
import { emailQueue } from "../lib/queue.js";

export async function sendWelcomeEmailJob(user) {

    await emailQueue.add("sendWelcomeEmail", {
        email: user.email,
        name: user.name,
    });

    console.log("Job added to queue");
}
```

---

# 9. API Route (Trigger Job)

## app/api/register/route.js

```js id="q10"
import { sendWelcomeEmailJob } from "../../../services/emailService.js";

export async function POST(req) {

    const body = await req.json();

    // simulate user creation
    const user = {
        name: body.name,
        email: body.email,
    };

    // add job to queue
    await sendWelcomeEmailJob(user);

    return Response.json({
        message: "User registered, email will be sent"
    });
}
```

# 10. Worker (Job Processor)

## worker/emailWorker.js

```js id="q11"
import { Worker } from "bullmq";
import { connection } from "../lib/redis.js";

const worker = new Worker(
    "emailQueue",
    async (job) => {

        if (job.name === "sendWelcomeEmail") {

            const { email, name } = job.data;

            console.log("Processing email job...");

            await sendEmail(email, name);
        }
    },
    { connection }
);

async function sendEmail(email, name) {

    console.log("Sending email to:", email);

    // simulate delay
    await new Promise(res => setTimeout(res, 2000));

    console.log(`Email sent to ${name} <${email}>`);
}
```

# 14. Worker Handling Multiple Jobs

```js id="q18"
const worker = new Worker(
    "emailQueue",
    async (job) => {

        switch (job.name) {

            case "sendWelcomeEmail":
                await sendEmail(job.data);
                break;

            case "sendOTP":
                await sendOTP(job.data);
                break;

            case "logUserActivity":
                console.log("Log:", job.data);
                break;
        }
    },
    { connection }
);
```

# 15. Retry System (Important)

```txt id="q19"

```

# 19. Best Practice Rules

```txt id="q24"
✔ Never send email inside API directly
✔ Always push heavy work to queue
✔ Run worker separately from Next.js
✔ Use retry + failure handling
✔ Keep queue jobs small and atomic
```
