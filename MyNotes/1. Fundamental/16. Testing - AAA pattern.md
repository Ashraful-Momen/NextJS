# Next.js Complete Testing Note (Jest + AAA Pattern + JavaScript)

# 1. What is Testing ?

Testing means checking whether application works correctly or not.

Testing helps to:

* Prevent Bugs
* Check Expected Output
* Protect Existing Features
* Improve Code Quality
* Safe Refactor

---

# 2. What is AAA Pattern ?

AAA = Arrange → Act → Assert

```txt
ARRANGE
Setup Data

    ↓

ACT
Run Function / Click Button

    ↓

ASSERT
Check Expected Result
```

---

# 3. Why Use AAA Pattern ?

Benefits:

* Cleaner Test
* Easy to Read
* Easy Debug
* Industry Standard
* Perfect for Jest

---

# 9. Configure Jest

## jest.config.js

```js
const nextJest = require("next/jest");

const createJestConfig = nextJest({

    dir: "./",
});

const customJestConfig = {

    testEnvironment: "jsdom",

    setupFilesAfterEnv: [
        "<rootDir>/jest.setup.js",
    ],

    moduleNameMapper: {

        "^@/(.*)$": "<rootDir>/$1",
    },
};

module.exports =
    createJestConfig(customJestConfig);
```

# 16. First Unit Test

## **tests**/unit/math.test.js

```js
import {
    add,
    multiply,
} from "@/lib/math";


describe("Math Functions", () => {

    test("should add two numbers", () => {

        // ARRANGE
        const a = 5;
        const b = 10;

        // ACT
        const result = add(a, b);

        // ASSERT
        expect(result).toBe(15);
    });


    test("should multiply numbers", () => {

        // ARRANGE
        const a = 2;
        const b = 4;

        // ACT
        const result = multiply(a, b);

        // ASSERT
        expect(result).toBe(8);
    });
});
```

# 20. Simple Counter Component

## components/Counter.jsx

```jsx
"use client";

import { useState } from "react";

export default function Counter() {

    const [count, setCount] =
        useState(0);

    return (
        <div>

            <h1>Count: {count}</h1>

            <button
                onClick={() => setCount(count + 1)}
            >
                Increment
            </button>

        </div>
    );
}
```

# 21. View Test Example

## **tests**/view/Counter.test.jsx

```jsx
import {
    render,
    screen,
} from "@testing-library/react";

import userEvent
from "@testing-library/user-event";

import Counter
from "@/components/Counter";


describe("Counter Component", () => {

    test("should increment count", async () => {

        // ARRANGE
        render(<Counter />);

        const button =
            screen.getByText("Increment");

        // ACT
        await userEvent.click(button);

        // ASSERT
        expect(
            screen.getByText("Count: 1")
        ).toBeInTheDocument();
    });
});
```
