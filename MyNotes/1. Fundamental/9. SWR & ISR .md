ISR means:

```txt id="r8v2mc"

```

ISR is a Next.js feature for:

```txt id="u4k9pb"

+
```

# 3. SWR vs ISR Core Difference

| SWR               | ISR                 |
| ----------------- | ------------------- |
| Client Side       | Server Side         |
| CSR Fetching      | Static Regeneration |
| Runs in Browser   | Runs on Server      |
| Dynamic User Data | Static Public Data  |

# 12. Basic SWR Example

## components/PostList.jsx

```jsx id="n3m7qa"
"use client";

import useSWR from "swr";

import { fetcher }
from "@/lib/fetcher";

export default function PostList() {

    const {

        data,

        error,

        isLoading,

    } = useSWR(

        "/api/posts",

        fetcher
    );

    // LOADING
    if (isLoading) {

        return <h1>Loading...</h1>;
    }

    // ERROR
    if (error) {

        return <h1>Error...</h1>;
    }

    return (

        <div>

            {

                data.map((post) => (

                    <h1 key={post.id}>

                        {post.title}

                    </h1>
                ))
            }

        </div>
    );
}
```
