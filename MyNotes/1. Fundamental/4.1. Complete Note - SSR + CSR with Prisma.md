# 2. SSR vs CSR

| Feature            | SSR                   | CSR                   |
| ------------------ | --------------------- | --------------------- |
| Full Meaning       | Server Side Rendering | Client Side Rendering |
| Runs On            | Server                | Browser               |
| Best For           | Data Fetching         | Button Click          |
| SEO                | YES                   | NO                    |
| Hooks              | NO                    | YES                   |
| useState           | NO                    | YES                   |
| Default in Next.js | YES                   | NO                    |

---

# 3. What is ORM ?

ORM = Object Relational Mapping

```txt id="jttw7g"
JavaScript Object
        ⇅
Database Table
```

Example:

```js id="6qj0bw"
await prisma.user.findMany()
```

Instead of:

```sql id="l1t9nq"
SELECT * FROM users;
```

---

# 4. Why Prisma ORM ?

Prisma ORM is modern ORM for Next.js.

Benefits:

* Easy CRUD
* Cleaner Code
* Type Safety
* Fast Query
* Easy Migration
* Perfect for React + Next.js

# 17. ADD USER COMPONENT

## components/AddButton.jsx

```jsx id="81rj9o"
"use client";

import { useState } from "react";

export default function AddButton() {

    const [name, setName] = useState("");
    const [email, setEmail] = useState("");

    async function addUser() {

        await fetch("/api/users", {

            method: "POST",

            headers: {
                "Content-Type": "application/json",
            },

            body: JSON.stringify({
                name,
                email,
            }),
        });

        alert("User Added");
    }

    return (
        <div>

            <input
                type="text"
                placeholder="Name"
                value={name}
                onChange={(e) => setName(e.target.value)}
            />

            <input
                type="email"
                placeholder="Email"
                value={email}
                onChange={(e) => setEmail(e.target.value)}
            />

            <button onClick={addUser}>
                Add User
            </button>

        </div>
    );
}
```

# 23. CREATE + READ API

## app/api/users/route.js

```js id="jlwm73"
import { prisma } from "@/lib/prisma";


// GET USERS
export async function GET() {

    const users =
        await prisma.user.findMany();

    return Response.json(users);
}


// CREATE USER
export async function POST(req) {

    const body = await req.json();

    const user =
        await prisma.user.create({

            data: {
                name: body.name,
                email: body.email,
            },
        });

    return Response.json({

        message: "User Created",

        data: user,
    });
}
```

# 24. UPDATE + DELETE API

## app/api/users/[id]/route.js

```js id="jlwm81"
import { prisma } from "@/lib/prisma";


// UPDATE USER
export async function PUT(req, { params }) {

    const body = await req.json();

    const user =
        await prisma.user.update({

            where: {
                id: Number(params.id),
            },

            data: {
                name: body.name,
            },
        });

    return Response.json({

        message: "User Updated",

        data: user,
    });
}


// DELETE USER
export async function DELETE(req, { params }) {

    await prisma.user.delete({

        where: {
            id: Number(params.id),
        },
    });

    return Response.json({

        message: "User Deleted",
    });
}
```

# 28. Interview Questions

## Q1: What is SSR ?

Server renders HTML before sending to browser.

---

## Q2: What is CSR ?

Browser renders UI after JavaScript loads.

---

## Q3: Why use Prisma ORM ?

Easy database query using JavaScript.

---

YES.

---

NO.
