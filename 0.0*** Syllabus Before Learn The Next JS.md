## 1:1 Relation

```prisma
model User {
  id      Int      @id @default(autoincrement())
  profile Profile?
}

model Profile {
  id     Int  @id @default(autoincrement())
  userId Int  @unique
  user   User @relation(fields: [userId], references: [id])
}
```

### Why `?`

`Profile?` means optional relation.

User may have:

* one profile
* or no profile

---

## 1:M Relation

```prisma
model User {
  id    Int    @id @default(autoincrement())
  posts Post[]
}

model Post {
  id     Int  @id @default(autoincrement())
  userId Int
  user   User @relation(fields: [userId], references: [id])
}
```

### Why `[]`

`Post[]` means multiple posts.

One user can have many posts.

---

## Many-to-Many Relation

```prisma
model Student {
  id       Int      @id @default(autoincrement())
  courses  Course[]
}

model Course {
  id       Int       @id @default(autoincrement())
  students Student[]
}
```

---

## Custom Pivot Table

```prisma
model StudentCourse {
  studentId Int
  courseId  Int

  student Student @relation(fields: [studentId], references: [id])
  course  Course  @relation(fields: [courseId], references: [id])

  @@id([studentId, courseId])
}
```

Used when pivot table needs:

* Extra columns
* Metadata
* Status
* Created date

# 16. Middleware

## middleware.js

```js
import { NextResponse } from "next/server";

export function middleware(req) {
  const token = req.cookies.get("token");

  if (!token) {
    return NextResponse.redirect(
      new URL("/login", req.url)
    );
  }

  return NextResponse.next();
}
```

# 32. SSR vs CSR (Very Important)

| Feature         | SSR       | CSR       |
| --------------- | --------- | --------- |
| Render Location | Server    | Browser   |
| SEO             | Excellent | Weak      |
| First Load      | Fast      | Slower    |
| Secure Data     | Yes       | No        |
| Browser API     | No        | Yes       |
| Realtime UX     | Limited   | Excellent |

---

## Use SSR When

* Need SEO
* Database query
* Authentication page
* Secure rendering
* Product page

---

## Use CSR When

* Dashboard
* Realtime updates
* Chat systems
* Interactive forms
* Browser events
